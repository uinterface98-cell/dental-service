IMG FOLDER — 70_dental-service
============================================================
Drop your own images here to replace the placeholders.
The page will use your images automatically — no code editing needed.

HOW TO USE:
  1. Name your photos:  image-01.jpg, image-02.jpg, image-03.jpg …
  2. Place them in this img/ folder (next to index.html → img/).
  3. Open index.html in a browser — your images load automatically.
  4. If a file is missing the original placeholder still shows,
     so the layout never breaks.

Recommended format : JPG or WEBP
Recommended size   : min 1200 px wide (larger = better quality)

TIP: Start with image-01.jpg for the most prominent image,
     then image-02.jpg for the second, and so on.
     Open the site in a browser to see which slot each number covers.
